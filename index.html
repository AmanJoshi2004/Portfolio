// 04. projects

Selected Work

01 NEW
Transaction Guardian — AI Fraud Risk Decision Lab

An interactive, end-to-end proof-of-concept that turns nine raw transaction signals (amount, device, location, velocity, merchant risk, time of day) into an explainable real-time decision: approve, verify, or escalate for review. Built to show that no single signal decides an outcome — the model reads the combination.

📊 260-tree Random Forest on 15,000 synthetic transactions · 77.4% precision · 75.9% recall · 0.766 F1 · 0.915 ROC-AUC

GitHub Live Demo
02
Sentiment Intelligence Platform (Production AI System)

End-to-end NLP platform processing 500K+ Amazon reviews using DistilBERT, RoBERTa, and Aspect-Based Sentiment Analysis to transform 76K raw aspects into 13 product intelligence dimensions. Paired with a RAG system (FAISS, ChromaDB, LangChain ReAct Agent on Llama 3.3 70B) for grounded, conversational product recommendations.

📊 0.83 Macro F1 · PySpark ETL pipelines · MLflow tracking · interactive Streamlit app

Production-ready web app for automated PCB defect detection, trained on a custom 9-class industrial dataset. Full computer-vision pipeline: OpenCV preprocessing, augmentation, object detection, and a real-time Streamlit inspection interface.
